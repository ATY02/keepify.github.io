# Keepify
Website for the Keepify senior project team.

## What's Included
1. Header (across all pages) - Team name and logo.
2. Home - A home page displaying our team members, sponsor, and coach.
3. About - A project info page describing the app and displaying its listing on the Shopify app store.
4. Deliverables - All document submissions to the senior project portal, approved by the sponsor.
5. Time Tracking Reports - A spreadsheet detailing how much time everyone has logged on different project items.
